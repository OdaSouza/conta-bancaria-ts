 ## Simulação de sistema bancário em Typescript.

Sistema bancário simulado. Apenas classes para exibir e demonstrar status do sistema.

OBS: app.ts roda todos os arquivos enquanto os outros são modulos. (class > arquivos.ts)

### Tecnologias usadas:

* Linguagem > Typescript
  
 Dependencias de desenvolvimento: 
  *ts-node: 1.0.9.2,
   *ts-node-dev: 2.0.0,
   *typescript: 6.0.3
